# NOTICE

This project (**rocket-track**) builds on:

- **Ultralytics YOLOv8** — detector training/inference (`ultralytics` package). See Ultralytics licensing for model/code terms.
- **Roboflow** — dataset export for the rocket class (`arbalesttest` / `rocket-tracking-pduic-ay8b4`, CC BY 4.0 per `data.yaml`).
- **SORT** — tracking algorithm described by Bewley et al. (2016); this repo contains an independent implementation under `src/rocket_track/track_sort.py`.
- **Arbalest** — university rocketry club context for the original imagery / labeling effort; this toolkit is a personal systems/CV project packaged for cloneable reuse.
